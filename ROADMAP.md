# Roadmap

The roadmap prioritizes correctness and low overhead over feature count.

## 2.x

- richer per-core CPU and per-interface/per-device drilldown
- process history with strict opt-in retention limits
- Intel/NVIDIA fixture corpus from more drivers
- DB migration tests across released schemas
- localization infrastructure
- accessibility audit for keyboard navigation and screen readers
- reproducible Debian package pipeline

## Explicit non-goals

- fleet monitoring
- cloud accounts
- remote agents
- Prometheus-compatible server mode
- browser-based dashboard
- system tuning or automatic overclock/power controls
